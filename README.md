# Smart Civil Legal Services Platform

Graduation project, Software Engineering, Al-Margib University (2026/2027).
Supervisor: Dr. Fawzi Al-Sharif

## Problem
Reviewing long contracts takes lawyers and clients a lot of time, and citizens
have no easy way to find the right legal specialist.

## Features (planned)
- AI contract analyzer: extracts key clauses and summarizes contracts
- Smart matching between clients and the right lawyer
- Encrypted storage of legal documents
- RAG knowledge base built from Libyan civil law texts

## Tech stack
Next.js · Python (FastAPI) · PostgreSQL + pgvector · LangChain · JWT · AES-256
